# pizza_hutt
# Pizza Hut Sales Analysis

## Project Overview
This project analyzes Pizza Hut sales data using SQL to identify sales trends, customer ordering patterns, and business performance.

## Tools Used
- MySQL
- SQL
- Git & GitHub

## Project Objectives
- Analyze total sales
- Identify top-selling pizzas
- Analyze orders and revenue
- Find important business insights
- Perform data quality checks

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- Aggregate Functions
- Subqueries
- Data Quality Checks

## Project Structure

- `data/` – Project data
- `database/` – Database schema and loading scripts
- `sql/` – SQL analysis queries
- `screenshots/` – Query result screenshots
- `create_project.py` – Project setup script

## Key Analysis
The SQL queries in this project are used to analyze Pizza Hut sales data and generate business-related insights.
